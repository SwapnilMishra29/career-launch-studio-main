# 🎓 CampusCraft – Resume & Portfolio Services for Students

CampusCraft is a student-focused platform that helps final-year and internship-seeking students build **ATS-friendly resumes** and **live portfolio websites** to boost their chances of getting shortlisted for jobs and internships.

🔗 **Live Website:**  
https://campuscraft-services.netlify.app/

---

## 🚀 Features

- ✅ Professional ATS-Optimized Resume Design
- ✅ Live Personal Portfolio Website
- ✅ Fast Delivery (2–3 Days)
- ✅ Free First Update
- ✅ Student-Friendly Pricing
- ✅ Referral Program (Earn up to ₹200 per successful referral)
- ✅ Manual Quality Check Before Delivery

---

## 🛠 Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS + ShadCN UI
- **Icons:** Lucide React
- **Hosting:** Netlify
- **Forms:** Google Forms (Order Management)
- **Design Tools:** Canva (Resume Design)

---

## 📦 Services Offered

- Resume Only  
- Portfolio Website Only  
- Resume + Portfolio Combo  
- Resume / Portfolio Update Services  

All services are tailored specifically for **college students and freshers**.

---

## 📝 How to Place an Order

1. Visit the website:  
   👉 https://campuscraft-services.netlify.app/
2. Click on **Order Now**
3. Fill the Google Order Form with your details
4. Our team will contact you within **12 hours**
5. After confirmation & payment, your work will be delivered within **2–3 days**
